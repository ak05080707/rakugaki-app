工務TODO 設置手順

iPhone・iPad・Windows PC で同じTODOを共有し、LINE・Outlook 2019・Plaud・TimeTree からも取り込める仕組みの設置手順です。Windows PC で、このページと Google を並べて進めると楽です。終わった手順は番号をクリックすると緑になります（進み具合はこのブラウザにだけ保存されます）。

A. スプレッドシートとスクリプトを作る

スプレッドシートを新しく作る

  1. いつものGoogleアカウント（Googleドライブと同じ）でログインした Chrome か Edge で sheets.new を開く
  2. 左上の 無題のスプレッドシート をクリックして、名前を 工務TODO に変える

Apps Script を開く

  1. スプレッドシートの上のメニュー 拡張機能 → Apps Script
  2. 新しいタブが開く。左上の 無題のプロジェクト をクリックして 工務TODO に変える

Code.gs を貼り付ける

  1. 左の一覧にある コード.gs を開く
  2. 中身をクリックして Ctrl+A → Delete で全部消す
  3. 下のボタンでコピー → エディタで Ctrl+V → Ctrl+S で保存
中身を見る


  

    
Index（画面）を追加する

    
    
      
  1. 左の ファイル の横の ＋ → HTML
    2. 
      
  2. 名前に Index と入れて Enter（「.html」は自動で付く。I は大文字）
    3. 
      
  3. 最初から入っている中身を全部消して、コピーしたものを貼り付け → 保存
    4. 
    

    

    
中身を見る

setup を実行して「合言葉」をもらう

    
    
      
  1. エディタ上のツールバーのプルダウン（myFunction などと表示）で setup を選ぶ → ▷ 実行
    2. 
      
  2. 承認が必要です → 権限を確認 → 自分のアカウントを選ぶ
    3. 
      
  3. このアプリは Google で確認されていません と出たら、左下の 詳細 → 工務TODO（安全ではないページ）に移動 → 許可（チェック欄があれば「すべて選択」）
    4.

「安全ではない」と出るのは、Googleの審査を受けていない自作スクリプトだからです。自分で作ったものなので問題ありません。

D. LINE から追加できるようにする（任意・15分）

  
自分専用の「LINE公式アカウント」（無料）を作り、そこに送った内容がTODOになる仕組みです。人から届いたLINEは、長押し →「転送」でこのアカウントに送ればTODOになります。


  

    
LINE公式アカウントを作る

    
    
      
  1. LINE公式アカウントの開設ページ →「LINE公式アカウントをはじめる」→ いつものLINEアカウントでログイン
    2. 
      
  2. アカウント名は 工務TODO、業種は「建設・不動産」など適当でOK → 作成（無料プランのまま）
    3. 
    


  

    
Messaging API をオンにする

    
    
      
  1. LINE Official Account Manager で「工務TODO」を開く
    2. 
      
  2. 右上の 設定 → 左の Messaging API → Messaging APIを利用する
    3. 
      
  3. プロバイダーを聞かれたら「新規作成」で名前は自分の名前など何でもOK → OK
    4. 
      
  4. 同じ画面の Webhook URL に、手順7で作った 自分専用URL（…/exec?key=合言葉） を貼り付けて 保存
    5. 
    


  

    
自動応答を切って、Webhook をオンにする

    
    
      
  1. 同じ 設定 の左メニュー 応答設定 を開く
    2. 
      
  2. チャット：オフ　／　あいさつメッセージ：オフ　／　Webhook：オン　／　応答メッセージ：オフ
    3. 
    

    
応答メッセージがオンのままだと「個別の返信はできません」という定型文が毎回返ってきます。


  

    
チャネルアクセストークンをコピーする

    
    
      
  1. LINE Developers コンソール を開いてLINEでログイン
    2. 
      
  2. 手順11で作ったプロバイダー → 工務TODO のチャネル → 上のタブ Messaging API設定
    3. 
      
  3. 一番下の チャネルアクセストークン（長期） → 発行 → 出てきた長い英数字をコピー
    4. 
      
  4. 同じページの Webhookの利用 がオンになっているか確認
    5. 
    

    
Webhook URL の 検証 ボタンはエラー（302など）になることがありますが、Googleの仕組み上よくあることで、実際のメッセージは届きます。手順15で試してください。


  

    
トークンを Apps Script に登録する

    
    
      
  1. Apps Script の画面に戻り、左の歯車 プロジェクトの設定
    2. 
      
  2. 一番下の スクリプト プロパティを追加
    3. 
      
  3. プロパティ：LINE_CHANNEL_ACCESS_TOKEN（コピーして貼るのが確実）　値：手順13のトークン → スクリプト プロパティを保存
    4. 
    

    

    
ここは再デプロイ不要です。すぐ反映されます。


  

    
友だち追加して、試しに送る

    
    
      
  1. LINE Developers の Messaging API設定 にあるQRコードを、iPhoneのLINEで読み取って友だち追加
    2. 
      
  2. 「明日 テスト」と送る → 「📝 追加しました：テスト（期限 …）」と返ってくれば成功。TODO画面にも LINE の緑バッジ付きで出ます
    3. 
      
  3. 「一覧」と送ると未完了の一覧、「完了 1」で1番を完了にできます
    4. 
    

    
最初にメッセージを送った人が「持ち主」として登録されます。必ず自分が最初に送ってください。毎朝7時に今日のTODOが届くのもこのアカウントからです。

H. コードを更新するとき（大事）

  

    
    
      
  1. Apps Script で Code.gs・Index.html を貼り替えて Ctrl+S（このページの手順3・4のボタンが常に最新版です）
    2. 
      
  2. デプロイ → デプロイを管理 → 今使っているデプロイの ✏ 鉛筆 → バージョン 新バージョン → デプロイ
    3. 
      
  3. スマホは TODO アプリを完全に閉じて開き直す。PC は Ctrl+F5
    4. 
    

    
「新しいデプロイ」は押さないでください。URLが変わり、LINE・スマホのホーム画面・Claude からつながらなくなります。URLが変わってしまった時は、LINE Developers の Webhook URL・スマホのホーム画面・Claude の設定（手順17〜18をやり直す）をすべて新しいURLに直します。

  


  
うまくいかない時

  

    
「URLの合言葉(key)が違います」と出る
URLの最後が ?key=合言葉 になっているか確認。手順7で作ったURLを使ってください。

    
「スクリプト関数が見つかりません: doGet」と出る
Code.gs が保存されていません。保存してから、デプロイ → デプロイを管理 → 鉛筆 → バージョン 新バージョン → デプロイ。

    
「setup() を先に実行してください」と出る
手順5をもう一度。プルダウンが setup になっているか確認。

    
LINEで送っても返事がない
①Webhook URL の最後が ?key=合言葉 になっているか　②応答設定で Webhook がオンか　③スクリプトプロパティの名前の綴り　を確認。スプレッドシートの LINE_LOG シートに記録があれば、届いてはいます（③の可能性大）。

    
PowerShell で「winget が見つかりません」
nodejs.org から LTS 版をダウンロードして入れてから、手順18をもう一度。

    
設定の開発者に komu-todo が出ない／failed になる
Claude をタスクトレイから完全に終了して起動し直す。それでもダメなら手順18をもう一度（何度やっても大丈夫。設定は上書きされます）。

    
TimeTree で「メールアドレスかパスワードが違います」
ブラウザで timetreeapp.com にメールアドレスでログインできるか確認（手順21）。LINE などでログインしている場合はメールアドレスの登録が必要です。

    
TimeTree で「回数制限中です」
ログインを何度も失敗すると一時的にロックされます。30分ほど待ってから手順22をもう一度。

    
LINE が急に反映されなくなった
LINE Developers の Webhook URL の 検証 が 404 なら、古いデプロイのURLのままです。デプロイを管理 で今のURLを確認し、?key=合言葉 を付けて貼り直します（302 なら正常）。

    
コードを更新したのに画面が変わらない
「新バージョン」でデプロイしたか確認（H）。そのうえでスマホはアプリを完全に閉じて開き直す、PC は Ctrl+F5。

    
画面が真っ白
HTMLファイルの名前が Index（Iが大文字）になっているか確認。
