# Outlookメール返信アシスタント（設定手順書）

Outlook 2019のメールを探して、Claudeが返信文を作り、**Outlookの「下書き」に保存する**ツールです。
**自動で送信することはありません。** 送信は、中身を確認してから自分でOutlookの送信ボタンを押します。

使い方は2通りあります。**おすすめは「A. デスクトップアプリ版」**（追加料金なし）です。

| | A. デスクトップアプリ版（おすすめ） | B. API版 |
|---|---|---|
| 料金 | **今のClaude月額プランの範囲内（追加料金なし）** | 使った分だけ（1通あたり数円〜10円くらい） |
| 使い方 | Claudeアプリのチャットで話しかける | 黒い画面で番号を選ぶ |
| 必要なもの | Claudeデスクトップアプリ（Windows版） | APIキー（別契約） |

---

## A. デスクトップアプリ版（追加料金なし）

### できること
Claudeデスクトップアプリのチャットで、こんなふうに頼むだけです。

> 山田建設から来た外構工事のメールを探して、「了承、10/3の9時に現場確認に伺う」で返信の下書きを作って

Claudeが次の順に進めます。
1. メールを探す（**仕分けルールで振り分けたサブフォルダも一緒に探します**）
2. 本文を読む
3. 返信文をチャットに表示する（「もっと短く」などと直してもらえます）
4. OKと言うと、Outlookの「下書き」に保存して、返信画面を開く

### 準備（最初の1回だけ）

**① Pythonを入れる**
1. https://www.python.org/downloads/ から「Download Python 3.x」をダウンロードする
2. インストール画面の一番下にある **「Add python.exe to PATH」にチェックを入れて**、「Install Now」を押す

**② Claudeデスクトップアプリを入れる**
1. https://claude.ai/download からWindows版をダウンロードして入れる
2. いつものアカウントでログインして、一度起動しておく

**③ ツールを置いて登録する**
1. この `outlook-claude` フォルダを、PCの好きな場所（例：ドキュメント）にコピーする
   - ※ 登録したあとにフォルダを移動すると動かなくなります。移動したら、もう一度この手順をやってください
2. **`setup_desktop.bat` をダブルクリック**する
3. 「登録しました」と出たら、**Claudeデスクトップアプリを完全に終了**して（画面右下のタスクトレイのClaudeアイコンを右クリックして「終了」）、起動し直す

**④ 設定ファイルを確認する**
`config.ini` をメモ帳で開いて、**[署名]** の電話番号（`（ここに電話番号）` の部分）を書き直してください。
書き直したら、Claudeデスクトップアプリを起動し直します。

### 使い方（毎回）
1. **Outlookを起動しておく**
2. Claudeデスクトップアプリで、メールのことを頼む
3. 初めて道具を使うときに「outlookの〜を使用しますか？」と聞かれるので「許可」を押す
4. 下書きが開いたら、内容を確認して自分で送信する

**頼み方の例**
- 「今週来た山田さんのメールを一覧にして」
- 「○○邸の件で来てる最新のメールに、見積は来週金曜までに出すと返信の下書きを作って」
- 「さっきの返信、もう少し短くして。OKなら下書き保存して」

## B. API版（使った分だけ料金がかかる）

Claudeアプリを使わずに、黒い画面で動かす版です。準備は、Aの①（Python）のあとに次の手順を行います。

1. https://console.anthropic.com/ で「Billing」にクレジットを追加して、「API Keys」でキー（`sk-ant-...`）を作る
2. コマンドプロンプトで `setx ANTHROPIC_API_KEY "sk-ant-..."` と入力する（そのあと、コマンドプロンプトを閉じる）
3. `setup.bat` をダブルクリックする
4. 使うときは `start.bat` をダブルクリック → キーワード → 番号 → 返信の方針 → `s` で下書きに保存

---

## こんなときは

| 症状 | 対処 |
|---|---|
| Outlookに「プログラムがアクセスしようとしています」と警告が出る | 「許可」を押す（10分間など時間を選べます）。ウイルス対策ソフトが最新なら出ないこともあります |
| Claudeアプリで道具が出てこない | アプリをタスクトレイから完全に終了して起動し直す。直らなければ `setup_desktop.bat` をもう一度 |
| メールが見つからない | 日数を増やす（「60日前まで探して」）。キーワードを短くする（「山田建設株式会社」→「山田」） |
| 返信文に【要確認：〜】が入っている | メールに書かれていない日付・金額などです。自分で書き足してから送信してください |

---

## 大事なこと（安全のため）

- **送信は必ず自分で。** このツールは下書きまでしか作りません
- 選んだメールの内容は、返信文を作るためにClaude（Anthropic社）に送られます。社外秘の扱いが厳しいメールでは使わないでください
- A版はClaudeの月額プランの利用枠を使います。大量のメールを一度に処理すると、枠を早く使い切ることがあります
