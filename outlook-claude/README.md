# Outlookメール返信アシスタント（設定手順書）

Outlook 2019のメールを探して、Claudeが返信文を作り、**Outlookの「下書き」に保存する**ツールです。
**自動で送信することはありません。** 送信は、中身を確認してから自分でOutlookの送信ボタンを押します。

---

## できること

1. キーワード（差出人・件名・本文）でメールを探す
   - 受信トレイだけでなく、**仕分けルールで振り分けたサブフォルダも一緒に探します**
2. 探したメールから1通を選び、「返信の方針」をひとこと入力する
   - 例：「了承。来週火曜の午前に現場確認に伺う」
3. Claudeが返信文を作る → 画面で確認する
   - 気に入らなければ `r` を押して「もっと短く」などと直してもらう
4. `s` を押すと、Outlookの「下書き」に保存して、返信画面を開く
   - 元のメールの引用も付いた状態です。確認してそのまま送信できます

---

## 準備（最初の1回だけ）

### ① Pythonを入れる
1. https://www.python.org/downloads/ から「Download Python 3.x」をダウンロードする
2. インストール画面の一番下にある **「Add python.exe to PATH」にチェックを入れて**、「Install Now」を押す

### ② ClaudeのAPIキーを取得する
> ※ 普段使っているClaude（claude.ai）の月額プランとは**別の契約**です。使った分だけの料金がかかります。
> メール1通の返信作成で、だいたい数円〜十数円程度です。

1. https://console.anthropic.com/ にログインする
2. 「Billing」でクレジットを追加する（まずは5ドル程度で十分です）
3. 「API Keys」→「Create Key」でキーを作り、表示された `sk-ant-...` をコピーする

### ③ APIキーをPCに登録する
1. スタートメニューで「cmd」と入力して「コマンドプロンプト」を開く
2. 次のように入力してEnterを押す（`sk-ant-...` の部分はコピーしたキーに置き換えます）
   ```
   setx ANTHROPIC_API_KEY "sk-ant-..."
   ```
3. 「成功: 指定した値は保存されました。」と出ればOK。**コマンドプロンプトを一度閉じます。**

### ④ ツールを置く
1. この `outlook-claude` フォルダを、PCの好きな場所（例：ドキュメント）にコピーする
2. **`setup.bat` をダブルクリック**する（必要な部品が自動で入ります）

### ⑤ 設定ファイルを確認する
`config.ini` をメモ帳で開いて、次の項目を確認・修正してください。
- **[署名]** の電話番号（`（ここに電話番号）` の部分）
- **[基本]** の「全員に返信」（CCの人にも返すなら `yes`）

## 使い方（毎回）

1. **Outlookを起動しておく**
2. **`start.bat` をダブルクリック**する
3. 画面の指示に従って入力する

```
探すキーワード（差出人・件名・本文）> 山田建設
何日前まで？（Enterで30日）>

  1. 09/22 10:15  山田 太郎          ○○邸 外構工事の件  [受信トレイ]
  2. 09/19 16:40  山田 太郎          見積書送付のお願い  [山田建設]

返信するメールの番号（Enterで検索に戻る）> 1
返信の方針をひとこと > 了承。10/3の9時に現場確認に伺う
（返信案が表示される）
[s] 下書きに保存  [r] 直してもらう  [q] やめる > s
→ Outlookの「下書き」に保存しました（送信はしていません）。
```

4. 終わるときは、キーワードを入れずにEnterを押します

## こんなときは

| 症状 | 対処 |
|---|---|
| Outlookに「プログラムがアクセスしようとしています」と警告が出る | 「許可」を押す（10分間など時間を選べます）。ウイルス対策ソフトが最新なら出ないこともあります |
| 「ANTHROPIC_API_KEY が設定されていません」と出る | 準備③をやり直す。登録後は `start.bat` を開き直す |
| 「APIキーが正しくありません」と出る | キーのコピーミスがないか確認して、準備③をやり直す |
| メールが見つからない | 日数を増やす。キーワードを短くする（例：「山田建設株式会社」→「山田」） |
| 返信文に【要確認：〜】が入っている | メールに書かれていない日付・金額などです。自分で書き足してから送信してください |

---

## 大事なこと（安全のため）

- **送信は必ず自分で。** このツールは下書きまでしか作りません
- 選んだメールの内容は、返信文を作るためにClaude（Anthropic社）に送られます。社外秘の扱いが厳しいメールでは使わないでください
- APIキーは他人に教えないでください。漏れた場合は console.anthropic.com でキーを削除して作り直します
